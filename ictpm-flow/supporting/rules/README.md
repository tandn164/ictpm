# Rules — Supporting Toolkit

Đọc theo thứ tự:

1. `inputs.md` — inventory slot (động)
2. `catalog.md` — ID tài liệu ↔ template
3. `content.md` — map Fact → từng loại form
4. `validation.md` — trước `ready_for_review` / `approved`
5. `SOURCE_AND_MAP.md` (thư mục module) — nguồn cấu trúc; **không** in branding vào draft

JSON làm việc: `artifacts/01_supporting.json`  
Fill draft chỉ khi `status=approved` (hoặc `--force`).  
Closure Report → `pm:closeout`, không duplicate.
