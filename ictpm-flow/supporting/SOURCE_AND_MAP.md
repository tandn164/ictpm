# Supporting Toolkit — nguồn template & map

Template làm việc: Việt hóa, Times New Roman 14.  
Nguồn gốc chỉ tham chiếu cấu trúc (không in branding vào draft).  
File gốc (nếu tải được) đặt trong `templates/_source/` — không sửa.

| ID | Tài liệu ICTPM | Format | Nguồn tham chiếu (cấu trúc) |
|----|----------------|--------|----------------------------|
| `stakeholder_analysis` | Phân tích stakeholder | xlsx | [Smartsheet / Mendelow power–interest](https://www.smartsheet.com/free-stakeholder-analysis-templates); [IT Management 101](https://www.itmanagement101.co.uk/stakeholder-analysis-template/) |
| `issues_actions` | Issues & Action Items DB | xlsx | [ProjectManager Issue Tracking](https://www.projectmanager.com/templates/issue-tracking-template) |
| `phase_exit_checklist` | Phase Exit Review Checklist | docx | [PM² Phase-exit Review Checklist](https://pm2.europa.eu/pm2-artefacts_en) |
| `peer_evaluation` | Peer Evaluation Form | docx | [CMU / UMich peer evaluation](https://crlt.umich.edu/sites/default/files/resource_files/CMU_peer%20evaluation_accessible.pdf) |
| `selection_matrix` | Project Selection Decision Matrix | xlsx | [Decision / Prioritisation Matrix](https://www.projectmanager.com/templates/decision-matrix-template) |
| `portfolio` | Project Portfolio Management | xlsx | [ProjectManager Portfolio](https://www.projectmanager.com/templates/project-portfolio-template); [Smartsheet PPM](https://www.smartsheet.com/content/project-portfolio-management-templates) |
| `stakeholder_post_eval` | Stakeholder Post Project Evaluation | docx | Post-project evaluation form pattern |
| `post_impl_survey` | Post-Implementation Survey | docx | [NYS ITS Post-Implementation Survey](https://its.ny.gov/system/files/documents/2022/11/5-closeout.pdf) |
| `project_review_closure` | Project Review & Closure Report | — | **→ `pm:closeout`** |

Pipeline agent: inventory → Fact → JSON + confidence → Manual → `approved` → fill.
