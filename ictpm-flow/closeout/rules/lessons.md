# Bài học kinh nghiệm (Lessons Learned)

## JSON

```json
"lessons": [
  {
    "category": "Scope|Schedule|Technical|Organization|Quality|Other",
    "what_happened": "...",
    "root_cause": "...",
    "recommendation": "...",
    "priority": "High|Middle|Low"
  }
]
```

Ưu tiên rút từ `risk_json` (rủi ro đã xảy ra / Mitigate hiệu quả) + Manual.  
Tối thiểu 3 lessons khi có đủ Fact; thiếu → hỏi Manual.
