# Rules — Báo cáo tổng kết dự án

1. `inputs.md` — inventory động  
2. `overview.md` — thông tin & tóm tắt kết quả  
3. `effectiveness.md` — hiệu quả quản lý (baseline vs thực tế)  
4. `lessons.md` — bài học kinh nghiệm  
5. `closure.md` — đóng hành chính, hợp đồng, lưu trữ  
6. `validation.md` — trước ready_for_review
