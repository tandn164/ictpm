# Rules — Master Plan

Đọc theo thứ tự khi lập PMP:

1. `inputs.md` — WBS, Master Schedule, HSDT (+ HSMT/Risk/RFP)
2. `overview.md` — tóm tắt dự án, scope, giả định
3. `roles.md` — vai trò
4. `communications.md` — ma trận giao tiếp
5. `schedule.md` — milestone / phase
6. `issues.md` — quản lý vấn đề
7. `risk_summary.md` — tóm tắt rủi ro (trỏ module risk)
8. `transition.md` — M&O / cut-over
9. `appendices.md` — Cost + Quality (phụ lục)
10. `validation.md` — kiểm tra trước ready_for_review
